# Changes register: main to bartcore

Every user-visible, C-consumer-visible or behavioural change the merge brings, merged and deduplicated from the five code-side slices. Base is main at cb290550, tip is bartcore at b7266da9; there are no main-only commits, so the diff between them is exactly what a merge brings.

`visibility` is user, C-consumer, build or internal. `breaking` is yes, no, or behavioural, meaning the same call returns a different result. `anchor` names a symbol or a path, never a line. `decision` points at the row in docs/decisions.md that settles the change where one applies.

## 6. Merge order and the intermediate states
